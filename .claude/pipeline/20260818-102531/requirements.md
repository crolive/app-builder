# Requirements — Task CLI

## 1. Project Name
Task CLI

## 2. What It Does
A CLI tool to manage a personal task list from the terminal. Quick add, list, and mark tasks done — nothing fancy.

## 3. Audience & Primary Use Case
Personal use, for developers who live in the terminal.

## 4. Tech Stack
Node.js. No preference on libraries/frameworks — flagged for planning.

## 5. Key Features
- Add a task
- List tasks
- Complete (mark done) a task
- Delete a task

## 6. Explicitly Out of Scope
- No sync
- No due dates
- No priorities

## 7. Hard Constraints
- Must run offline
- No external APIs
