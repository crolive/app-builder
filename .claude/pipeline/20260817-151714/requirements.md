# Requirements — Todo Tracker

## 1. Project Name
Todo Tracker

## 2. What It Does
A CLI tool to manage a personal task list from the terminal.

## 3. Who It's For
Personal use, for developers who live in the terminal.

## 4. Tech Stack
- Runtime: Node.js
- Libraries: No preference

## 5. Key Features
- Add a task
- List all tasks
- Complete a task
- Delete a task

## 6. Non-Goals
- No sync
- No due dates
- No priorities

## 7. Hard Constraints
- Must run offline
- No external APIs
